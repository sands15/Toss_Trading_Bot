# SOXL/SOXS AI 가상투자 실험

1000만원(원화)으로 시작하는 **가상** 투자 실험입니다. AI가 매일 반도체 뉴스와
시장 상황을 보고 `SOXL`(반도체 3배 상승), `SOXS`(반도체 3배 하락), `현금` 중
하나를 고릅니다.

## 본체 봇과의 관계

- 이 폴더는 저장소의 터틀/모멘텀 봇(`src/turtle_bot`)과 **완전히 분리된 실험**입니다.
- 본체의 원칙("AI는 설명 전용")은 그대로 유지되고, 이 실험에는 적용되지 않습니다.
- 토스 API, 실제 계좌, 실제 주문을 **전혀 사용하지 않습니다**. 체결은 모두 가상입니다.
- `ledger.py`는 표준 라이브러리만 사용하고 `turtle_bot` 패키지를 import 하지 않습니다.

## 하루 흐름 (한국 시간, 평일)

| 시각 | 작업 |
|---|---|
| 22:30 무렵 | 장 시작 전 판단: 뉴스·시장 점검 → `ledger.py decide` → `journal/날짜.md` 작성 |
| 06:30 무렵 | 장 마감 후 정산: 시가·종가 입력 → `ledger.py settle` → 판단 결과 복기 |

판단은 그날 미국 정규장 **시가**에 체결된 것으로 계산하고, **종가**로 평가합니다.
자세한 절차는 [PLAYBOOK.md](PLAYBOOK.md)를 따릅니다.

## 규칙 (ledger.py가 강제)

- 선택지: `SOXL`, `SOXS`, `CASH` 중 하나. 두 상품을 동시에 보유하지 않음
- 한 번에 투입하는 비중: 현금의 최대 50%
- 손절: 진입가 대비 종가 -10% 이하 → 다음 시가에 강제 청산
- 최대 보유: 5거래일 → 다음 시가에 강제 청산
- 강제 청산 다음 거래일은 현금만 허용
- 비용: 매매마다 수수료 0.1% + 슬리피지 0.05%
- 판단에는 반드시 이유를 기록

## 판단 가이드 (AI가 지킬 것)

- NVDA 등 지수 상위 종목의 큰 실적 발표 전날, FOMC/CPI 발표 당일에는 현금 대기를 우선 검토
- 확신이 낮으면 현금. 매일 매매할 필요 없음
- 이미 가격에 반영된 뉴스인지(장전 거래 가격, 선물) 반드시 확인

## 비교 기준

첫 정산일 시가에 전액을 넣고 그냥 들고 있었을 때와 비교합니다.

- `SOXX` 보유 (1배 반도체 ETF)
- `SOXL` 보유 (3배, 아무것도 안 하고 들고 있기)

## 파일

- `ledger.py` 장부 계산 / `test_ledger.py` 테스트
- `records/state.json` 현재 상태, `records/daily.csv` 일별 평가액, `records/trades.csv` 매매 기록
- `journal/YYYY-MM-DD.md` 일별 뉴스 요약, 판단, 복기
- `SOURCES.md` 뉴스 매체 목록

```bash
python3 ledger.py status
```
