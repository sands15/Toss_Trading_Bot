# 예약 세션 작업 절차

모든 명령은 `experiments/soxl_ai_paper/` 폴더에서 실행합니다.
이 실험은 가상투자입니다. 토스 API·실제 계좌·실제 주문을 절대 사용하지 않습니다.
`src/`, `ops/`, `config/` 등 이 폴더 밖의 파일은 수정하지 않습니다.

## A. 장 시작 전 판단 (한국 시간 22:30 무렵)

1. 오늘(미국 날짜 기준)이 미국 휴장일이면 저널에 "휴장"만 적고 종료.
2. `records/state.json`이 없으면 오늘 USD/KRW 환율을 확인해
   `python3 ledger.py init --date <미국날짜> --krw 10000000 --fx <환율>` 실행.
3. `python3 ledger.py status`로 현재 상태 확인. 강제 청산 예정이면 CASH만 가능.
4. `SOURCES.md` 매체 위주로 지난 24시간 뉴스를 찾아 핵심 이슈 10개 이내로 요약.
   이슈마다 호재/악재/중립과 영향 종목을 표시.
5. 시장 점검: 나스닥 선물, VIX, 미 10년물 금리, 지수 상위 종목 장전 거래 가격,
   오늘·내일 실적/경제지표 일정.
6. 판단 후 기록:
   `python3 ledger.py decide --date <미국날짜> --action SOXL|SOXS|CASH --weight 0.1~0.5 --reason "<한 줄 이유>"`
   거부되면 오류 내용을 읽고 규칙 안에서 다시 판단.
7. `journal/<미국날짜>.md` 작성: 뉴스 요약 / 시장 점검 / 판단과 이유 / 확신도(낮음·중간·높음) / 출처 링크.

## B. 장 마감 후 정산 (한국 시간 06:30 무렵)

1. 방금 끝난 미국 거래일이 휴장이었으면 종료.
2. SOXL·SOXS·SOXX의 그날 **정규장 시가와 종가**, USD/KRW 환율을 두 곳 이상에서 확인.
3. `python3 ledger.py settle --date <미국날짜> --open SOXL=..,SOXS=..,SOXX=.. --close SOXL=..,SOXS=..,SOXX=.. --fx <환율>`
4. 해당 날짜 저널 아래에 "정산" 섹션 추가: 가격과 출처, 평가액, 판단이 맞았는지,
   다음에 참고할 점 한두 줄.

## 공통: 저장

- `git pull --rebase` 후 변경 파일만 커밋하고 push.
- 커밋 메시지 예: `soxl-paper: 2026-11-02 판단` / `soxl-paper: 2026-11-02 정산`
- 가격을 확인하지 못했으면 추측하지 말고 정산을 건너뛴 뒤 저널에 이유를 적는다.
  다음 정산 때 빠진 날짜부터 순서대로 처리한다.
